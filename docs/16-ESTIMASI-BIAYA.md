# Nusantara ERP — Paket Langganan

| | |
|---|---|
| **Harga** | **Rp 300.000 / bulan** (belum termasuk PPN) |
| Termasuk | Seluruh fitur aplikasi, uji coba gratis 30 hari, pemasangan, pindah data dari Excel, pemeliharaan, cadangan data harian, perubahan kecil (form, menu, laporan), bantuan lewat WhatsApp/telepon |

## Batas pemakaian

| | Batas |
|---|---|
| Data transaksi (PO, surat jalan, faktur, pembayaran, biaya) | ±500.000 dokumen |
| Foto DO dan surat jalan tersimpan | ±12.500 foto |
| Baca foto DO otomatis | ±1.000 foto per bulan |
| Pemakaian harian | ±400 kali aplikasi dibuka per hari |

## Catatan

- **Melewati batas:** biaya server dan penyimpanan tambahan dibicarakan terlebih dulu. Pemakaian dipantau dan Ibu diberi tahu sebelum batas tercapai.
- **Baca foto DO otomatis:** ketepatan hasil bergantung pada kualitas foto, yaitu ketajaman, cahaya, sudut pengambilan, dan cetakan DO yang pucat atau terlipat. Foto yang kurang jelas ditandai untuk dicek admin, dan angka dari foto tidak dicatat tanpa pemeriksaan.
- **Fitur besar baru** di luar perubahan kecil dihitung per fitur dan disepakati sebelum dikerjakan.
